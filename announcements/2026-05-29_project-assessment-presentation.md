## Project Scoring Rubric

### 1. Proposal (10%) — 2 slides

| Criteria | Description |
|----------|-------------|
| 1. Project Title & Team Members | Introduce the project and key personnel |
| 2. Motivation for Transformation | The pain-points/reasons driving the change |
| 3. Current Process Description | Overview of existing processes using a clear flow chart/diagram |
| 4. Key Stakeholders/Users | Identify who will be impacted or involved |
| 5. Initial To-Be Process Ideas | Initial vision for the future state (high level only) |
| 6. Anticipated Tech/Tools | Outline the technologies or tools you plan to use |

### 2. Final Presentation (20%) — max 8 slides · 10 mins + 5 mins Q&A

| Criteria | Description |
|----------|-------------|
| 1. Problem Understanding & As-Is Analysis | Clear explanation and visualization of the current state |
| 2. Stakeholder & User Journey Mapping | Insightful identification of key users and their needs |
| 3. To-Be Process Design | Creativity, feasibility, and depth of the redesigned process |
| 4. Constraints, Requirements & Change Management | Thoughtful handling of limitations and implementation considerations |
| 5. Value Addition & Impact | Quantified or well-argued value delivered (efficiency, accuracy, etc.) |
| 6. Presentation Quality | Clarity, structure, visuals, timing, and articulation |
| 7. Q&A Handling | Confident, informed, and concise responses to questions |
